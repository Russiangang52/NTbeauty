# NT Beauty — сайт салона красоты

Многостраничный сайт салона **NT Beauty** (Москва, проспект Защитников Москвы, 12, м. Некрасовка).
Все данные — из карточки организации в Яндекс Картах:
<https://yandex.ru/maps/org/nt_byuti/38042135240/>

Дизайн, компоненты и структура — те же, что у исходного шаблона; заменены только данные и тексты.

## Запуск и сборка

```bash
npm install
npm run dev      # локальная разработка
npm run build    # сборка → dist/index.html (один автономный файл)
```

Публикация на GitHub Pages — автоматически через `.github/workflows/deploy.yml`:
Settings → Pages → Source = **GitHub Actions**, затем `git push` в `main`.
Готовый `dist/index.html` можно также просто загрузить на любой хостинг.

Публиковать нужно **собранный** `dist/`, а не исходный `index.html` из корня.
Роутинг на hash (`#/services`, `#/masters`, …) — работает на любом хостинге без настройки.

## Где что менять

Практически всё лежит в **`src/data/salon.ts`**: телефон, адрес, часы работы, ссылки, прайс,
мастера, отзывы, фото, удобства. Мета-теги и JSON-LD — в `index.html`, тексты заголовков
страниц — в `src/App.tsx` (`meta`).

## Важно: что проверить

- **Ссылка онлайн-записи** — `salon.booking` в `salon.ts`: открывает запись в Яндекс Картах (меню услуг салона).
- **Часы работы.** В карточке видно только «открыто до 22:00». Полный график по дням — впишите в
  `salon.hours` и на странице «Контакты».
- **Фото.** Галерея карточки (64 фото) не отдаёт список снимков при чтении страницы, поэтому
  использованы 2 фото салона из шапки карточки и фото работ из отзывов гостей. Чтобы добавить
  свои — вставьте id фото вида `12345/2a000...` в массив `photoIds` в `salon.ts`.
- **Мастера.** Имена и описания составлены по отзывам гостей. Фото мастеров в карточке нет —
  показаны инициалы. Проверьте роли и при необходимости поправьте.
- **Прайс.** Взят из раздела «Товары и услуги» (обновлён 5 октября). Позиции «Лёгкий дизайн — 50 ₽»,
  «Френч — 400 ₽», «Сложный дизайн — 1 000 ₽» выглядят как доплаты к маникюру — уточните подпись.
- **Telegram.** Ссылка `t.me/+79998146444` взята из карточки (по номеру телефона).
